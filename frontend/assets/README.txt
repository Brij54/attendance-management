Place your custom login images in this directory:

1. Logo Image:
   - File Path: frontend/assets/logo.png (or logo.jpg or logo.svg)
   - Usage: Appears at the center top of the left branding panel above "International Institute of Information Technology Bangalore".

2. Background Image (Optional):
   - File Path: frontend/assets/bg.png (or bg.jpg)
   - Usage: Used as the full left-panel background image instead of the default cyan/blue ocean gradient.
